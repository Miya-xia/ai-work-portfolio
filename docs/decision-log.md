# 决策记录

这里是协作过程的脱敏摘要，不是原始聊天逐字记录，也不包含工作文件。

| 问题 | 决策 | 可检查结果 |
| --- | --- | --- |
| 线性材料不方便按兴趣展开 | 用柜子物件组织章节，同时保留上一章 / 下一章 | 首页七个物件，章节底部导航 |
| 开场影响演示节奏 | 短开场，可跳过、重播；深链接不播放 | 跳过按钮、Esc、减少动画设置 |
| 自动播放不方便解释 | 五个步骤改为点击查看 | 工作流 tab 与键盘左右切换 |
| 详情信息过小、重复标题占位 | 删除不提供信息的标题，扩大内容与插图 | 公开内容练习页可直接浏览 |
| AI 扩写可能改变原意 | 明确原文保护和增补边界 | 案例中记录该工作原则，不公开原文 |
| 容易把团队成果计为个人独立成果 | 分清本人业务贡献、AI 辅助与团队工程 | 案例与证据页明确说明 |
| 演示容易被误认为真实模型 | 使用完全虚构的固定数据，并反复标注范围 | 场景数据、页面说明、无网络模型调用 |
| 公开作品含有原始工作资料风险 | 独立公开目录、重写内容、原创配图、白名单检查 | tests/public.test.cjs 与发布目录限制 |
| 网站编辑不应改变公共代码 | 只保存在访问者本机；提供导出与清除 | 草稿控件、HTML 下载、本地清除 |

每次新发布仍需要审阅新增材料是否适合公开。文件扫描是辅助检查，不代替人工判断。
