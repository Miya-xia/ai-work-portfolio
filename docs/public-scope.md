# 公开范围与隐私

## 可以公开的内容

独立整理的个人项目说明、业务方法、交互代码、原创 CSS / SVG、虚构消息与虚构内容练习。公开身份使用本人姓名与本人的 GitHub 用户名，不展示联系方式、学历或详细履历。

## 本仓库不包含

原始工作汇报、简历附件、公司研究数据、品牌手册、同事署名与照片、内部文档 / 设计链接、后台地址、客户对话、鉴权凭证、模型密钥及真实业务指标。

## 访客输入

所有输入控件仅供虚构演示。页面会尝试把草稿写入访问者当前浏览器的 localStorage；清除按钮只清除此项目的草稿，不清除其他网站信息。导出 HTML 包含访问者输入，分享前请自行核对。

网站没有项目自建的远程数据写入、统计、广告或模型接口。GitHub Pages 作为托管服务仍可能处理访问日志，不能把静态站点描述为“没有任何数据处理”。

## AI 能力与贡献声明

代码、技术检查与部署由 AI 辅助。个人贡献侧重业务问题、需求表达、内容与视觉反馈、协同与人工审核。不把代码公开等同于独立工程能力，不用虚构演示声称真实业务效果。

## 维护规则

后续发布只使用这份隔离的公开项目。不要把整个工作目录、原始文件夹或整份离线汇报复制进仓库。访问限制不能靠隐藏按钮、前端密码或不分享链接来实现。
